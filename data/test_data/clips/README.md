# VCD test clips

The clips in this directory are selected from the
[Microsoft Video Conferencing Dataset (VCD)](https://github.com/microsoft/VCD).
File names identify the prepared resolution and frame rate. Files ending in `.nv12.gz` contain NV12
video compressed with gzip.
